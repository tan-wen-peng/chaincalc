# 尺寸链与公差堆叠计算工具 chaincalc

给结构工程师用的**命令行公差堆叠计算器**：输入装配尺寸链，输出封闭环的极值法结果、
概率法（RSS）结果、超差概率，以及给定封闭环公差时的反向公差分配建议；并支持把
GD&T 标注换算成等效公差带参与计算。

纯 Python 标准库 + openpyxl，无第三方科学计算依赖，跑得动、读得懂、改得动。

## 1. 能做什么

| 能力 | 说明 |
|---|---|
| 封闭环求解 | 极值法（完全互换）与概率法（大数互换 / RSS）双口径 |
| 合格性判定 | 上下限裕度、超差概率（PPM）、Cp / Cpk、分布中心偏移诊断 |
| 公差贡献分解 | 每个环占极值法公差线的比例、占 RSS 方差份额，指出优化优先级 |
| 反向公差分配 | 等精度法（默认）/ 等公差法 / 等比法，支持标准件锁定、只收紧不放宽 |
| GD&T 换算 | 位置度、同轴度、圆跳动、平面度、平行度等 15 种特征折算成等效尺寸环，支持 Ⓜ 补偿 |
| 计算书 | 一键输出 Markdown + 自包含 HTML |
| 输入 | Excel 模板（给同事）或 JSON（给版本管理） |

## 2. 快速开始

```
# 环境：Python 3.9+，只有生成/读取 Excel 才需要 openpyxl
pip install openpyxl

# 1) 生成 Excel 输入模板
python main.py template templates/尺寸链输入模板.xlsx

# 2) 求解并输出计算书（同时打印到终端）
#    先用模板自带的示例行跑通一条链
python main.py calc templates/尺寸链输入模板.xlsx

# 3) 只做反向公差分配
python main.py alloc templates/尺寸链输入模板.xlsx --target 0.20

# 4) GD&T 单条换算
python main.py gdt --feature 位置度 --value 0.20 --mmc --size-tol 0.20

# 5) 列出支持的几何公差特征
python main.py features

# 6) 自检
python -m unittest discover -s tests       # 36 项单元测试
python tests/check_parity.py               # Excel 与 JSON 输入结果一致性
```

`calc` 不加 `--out` 时，计算书默认写到输入文件同目录的 `<文件名>_计算书.md`；
加 `--html` 再出一份可直接发给评审的 HTML。

> **关于 `cases/` 目录**：三个实战案例是本地私有资料（含真实装配数据），已列入 `.gitignore`，不随本仓库发布。仓库内可直接运行的是 `templates/尺寸链输入模板.xlsx`。

## 4. 输入格式

### 4.1 JSON

```json
{
  "title": "案例1 转轴组件轴向间隙链",
  "closed_name": "端盖端面与轴承外圈端面的轴向间隙 X",
  "limit_low": 0.05, "limit_high": 0.30,
  "target_tol": 0.25, "alloc_method": "it", "alloc_mode": "wc",
  "rings": [
    {"name": "轴承座内腔深度 A1", "nominal": 40.00, "es": 0.10, "ei": 0.00, "sign": 1},
    {"name": "轴承宽度 A2", "nominal": 12.00, "es": 0.00, "ei": -0.12, "sign": -1, "fixed": true}
  ],
  "gdt": [
    {"name": "端面圆跳动", "feature": "圆跳动", "value": 0.02, "kind": "减环", "ref_size": 26.0}
  ]
}
```

| 字段 | 含义 |
|---|---|
| `sign` | `+1` 增环（使封闭环增大）、`-1` 减环 |
| `es` / `ei` | 上/下偏差（mm，代数值）。填反了会自动纠正 |
| `k` | 相对分布系数，正态 1.0、三角 1.22、均匀 1.73，仅概率法用 |
| `e` | 相对不对称系数，分布偏斜时微调中间偏差，一般填 0 |
| `fixed` | `true` 表示标准件/采购件，分配时锁定不可改 |
| `ref_size` | 要素实际尺寸，仅等精度法取 i(D) 用；GD&T 环必填 |
| `limit_low/`limit_high` | 封闭环的验收上下限（绝对值 mm） |

### 4.2 Excel

`python main.py template out.xlsx` 生成四张表：

1. **说明** —— 填写指引
2. **参数** —— 项目名称、封闭环名称/上下限/名义值、目标公差、分配方法、计算口径
3. **尺寸链** —— 每行一个组成环：环名称、类型（增环/减环，带下拉）、基本尺寸、上/下偏差、
   分布系数 k、不对称系数 e、固定、来源、备注
4. **GD&T** —— 几何特征、规格值、类型、是否 Ⓜ、尺寸公差、要素尺寸、补偿方式、作用

两张表可以混用：GD&T 表里的行会被自动换算成等效环追加进尺寸链。

## 5. 算法与建模约定

### 5.1 极值法（完全互换）

```
A0  = Σ ξi·Ai                      ξi = +1 增环 / -1 减环
ES0 = Σ_增环 ESi - Σ_减环 EIi
EI0 = Σ_增环 EIi - Σ_减环 ESi
T0  = Σ Ti
```

### 5.2 概率法（RSS）

```
Δi  = (ESi + EIi) / 2              中间偏差
Δ0  = Σ ξi·(Δi + ei·Ti/2)
T0  = √( Σ (ki·Ti)² )              等价于 6σ0
σ0  = T0 / 6
E S0' = Δ0 + T0/2 ,  EI0' = Δ0 - T0/2
P超差 = Φ((LSL-μ)/σ0) + 1 - Φ((USL-μ)/σ0) ,  μ = A0 + Δ0
```

**关于 k（相对分布系数）—— 这个约定必须写清楚，否则结论会被误读：**

`k` 定义为 `k = 6σ / T`，即"该环实际分布的 6σ 宽度与它图纸公差带宽度之比"。
正态分布 k=1；均匀分布（形状误差、单件小批）k=1.73；三角分布（配作、修配）k=1.22。
于是 T0 公式给出的 T0 恰好等于封闭环的 6σ0——这与教材和 GB/T 5847 的口径一致。

k 填错的代价是实打实的。案例 3 里塑胶件 k=1.17、两条平面度 k=1.73，
全部按 k=1 算会把 T0 从 **0.386 mm 低估到 0.332 mm**，超差率从 **1.80% 算成 0.73%**。

### 5.3 反向公差分配

目标公差先扣除锁定环（标准件）的占用，剩余预算按三种方法分配到自制环：

- `it` 等精度法（默认）：由 GB/T 1800.1 的标准公差因子 `i = 0.45·D^(1/3) + 0.001·D`（µm）
  求出统一的公差等级系数 `a`，各环取同一 IT 等级，再给出对应标注
- `equal` 等公差法：所有环取同一公差
- `proportional` 等比法：按现有公差或给定权重成比例缩放

两条**工程约束**（很多公式推导里没有，但实际必须遵守）：

1. **只收紧、不放宽**：若某环算出的建议公差大于它现有公差，说明它本来就够紧，
   保持原值，把省下的预算让给其它环（水位填充）。给一个已标 ±0.03 的面建议 ±0.08 毫无意义。
2. **概率法口径必须与求解器一致**：预算按方差 `(ki·Ti)²` 记账，否则"分配说可行、回验却超差"。

分配后会**自动回验**：把建议公差写回一条新链重新求解，报告里给出极值法/概率法两行结果。
这一步能立刻暴露"分配解决了 T0、但没解决中心偏移"的情况（见案例 1）。

### 5.4 GD&T → 等效公差带

换算原则（`python main.py features` 可查表）：

1. 一条几何公差 t 界定的公差带宽度，就是它给尺寸链带来的变动量全宽：**T_eq = t**
2. **位置类**（位置度/同轴度/同心度/对称度/圆跳动）：界定中心要素的可偏范围，
   按对称双向 ±t/2 处理，分布接近正态 → k=1.0
3. **形状/方向类**（平面度/直线度/圆度/圆柱度/平行度/垂直度/倾斜度）：界定要素本身对理想形状的偏离，
   只会单向"吃掉"间隙 → 按 [0, t] 单向处理，均匀分布 → k=1.73
4. **Ⓜ 最大实体要求**：bonus = |实际尺寸 − MMC|。最坏情况 bonus=0；
   概率法可取均值（尺寸公差的一半）。注意：若尺寸公差本身已作为一环入链，
   再叠加全额 bonus 会**重复计算**——这是常见错误。

## 7. 已知边界（故意不做的部分）

- 不做图形界面。命令行 + Excel 模板已经覆盖同事协作场景，GUI 不增加计算价值。
- 不做二维/三维几何链自动提取，尺寸链要人手工建。自动提取需要 CAD 二次开发，超出本工具范围。
- 径向链、角度链目前按"等效线性量"人工折算后录入，不内置向量合成。
- 概率法结果成立的前提是**过程受控**（Cpk ≥ 1.33 才有意义）。若工艺能力不足，
  概率法算出来再漂亮也是纸上数字，报告里会给 Cpk/Cp 提示。

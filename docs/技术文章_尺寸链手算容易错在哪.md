# 尺寸链手算容易错在哪：7 个现场高频错误与可复算的反例

公差堆叠这件事，公式三行就能写完，但我在评审里见过的手算错误，几乎每次都能落在下面 7 类里。
更麻烦的是：**这些错误大多不会算出一个"看起来不对"的结果**——它会算出一个更漂亮的、
反而让你放心签字的数字。

下面每一条都配一个用 [chaincalc] 跑出来的可复算反例，数字直接取自仓库里的
`cases/` 目录，你可以自己改一个数再看结论怎么翻。

---

## 错误 1：减环的上下偏差忘了互换

封闭环的上偏差来自**增环的上偏差减去减环的下偏差**，下偏差来自**增环的下偏差减去减环的上偏差**。
两个下标是交叉的。手算时一顺手把减环也按"上减上、下减下"处理，就会错。

案例 1（转轴组件轴向间隙链，X = A1 − A2 − A3 − A4）：

| 环 | 基本尺寸 | 上偏差 | 下偏差 | 类型 |
|---|---|---|---|---|
| A1 轴承座内腔深度 | 40.00 | +0.10 | 0 | 增环 |
| A2 轴承宽度 | 12.00 | 0 | −0.12 | 减环 |
| A3 隔套长度 | 22.00 | +0.05 | −0.05 | 减环 |
| A4 端盖凸台高度 | 5.85 | 0 | −0.05 | 减环 |

正确：ES0 = +0.32、EI0 = −0.05，间隙 **0.10 ~ 0.47 mm**。
不互换：ES0 = +0.05、EI0 = +0.22，得到 **0.20 ~ 0.37 mm**。

错的算法把区间从 0.37 mm 宽收窄到 0.17 mm，而且**两端都更"安全"**：最小间隙从 0.10 变成 0.20，
看起来离干涉远了一倍。如果你只检查"符号有没有写反"，恰好就在这里翻不过去——
注意 EI0 > ES0，这是一个自相矛盾的信号，**看到上偏差小于下偏差就该立刻停手**。

## 错误 2：用 A0 ± ΣT/2 代替真实的偏差区间

这是最常见的一条。很多人算完 ΣT 就直接写 `A0 ± ΣT/2`，把整条链默认成对称分布。
但各环偏差明显不对称（轴承一律 0/−0.12，端盖一律 0/−0.05）时，这个假设直接错位。

同一个案例 1：

- 真实区间：**0.100 ~ 0.470 mm**（中心 0.285）
- 对称假设：**−0.035 ~ 0.335 mm**（中心 0.150）

两者中心差了 **0.135 mm**——正好等于中间偏差 Δ0。也就是说：你以为的最小间隙是 −0.035（干涉！），
实际是 0.100（还有富余）；你以为的最大间隙是 0.335，实际是 0.470（超差 0.17）。

一个把结论从"干涉"翻成"通过"，另一个把它从"通过"翻成"超差"。全错，方向相反。

## 错误 3：只盯 T0，不看 Δ0 —— Cp 好看，Cpk 难看

T0 只描述"多宽"，Δ0 描述"中心在哪"，验收看的是**中心 + 半宽**有没有跑出上下限。

案例 1 原始设计：

- 极值法 T0 = 0.370，要求 0.25 → 直觉是"公差太大，压缩它"
- 概率法 T0 = 0.1921，σ0 = 0.0320，**Cp = 1.30**（看起来相当健康）
- 但 **Cpk = 0.156**，超差率 **31.97%**，且全部集中在上限侧

因为 Δ0 = +0.135 把分布中心顶到 0.285，而要求中心是 0.175。
此时最优动作不是收紧任何一条公差，而是**把名义尺寸挪 0.11 mm**。案例 1 的 v2 方案就是这么做的
（端盖凸台 5.85 → 5.96，其余不动）：概率法立刻从 31.97% 掉到 **9.45e-05**，Cpk 从 0.16 回到 1.30，
成本只多了一次 CNC 对刀。

> 记住这个判据：**Cp 高而 Cpk 低 = 公差给得够、位置放错了**。先去动名义尺寸，再考虑收紧公差。

## 错误 4：把概率法当挡箭牌

概率法（RSS）能显著缩小封闭环公差带——案例 1 里极值 0.370 对概率 0.1921，比值接近 √n。
于是它很容易被拿来"救"一个根本放不下的设计。但概率法只在两种情况下成立：

1. 各环分布独立且**过程受控**（不然 6σ 就没有物理意义）；
2. 组成环足够多、单环不主导。

案例 2（花鼓轴承轴向链）就是概率法真正该用的场合，但要注意它的前提：

- 极值法 T0 = 0.470，要求 0.25 → 差得离谱，极值法**永远不可能过**
- 概率法 T0 = 0.2090、±3σ = 0.140 ~ 0.350，落在 0.10~0.35 内，超差率 **0.131%**，Cpk 1.005

原因是这条链里有两条标准件：左右轴承各 0.12，合计 0.24——**单这两条就吃掉了 0.25 预算的 96%**，
剩下的花鼓壳、隔套、波形垫圈、两条圆跳动只能分 0.01。这种结构性矛盾再怎么分配也解不开，
所以结论应该是"**这条链按概率法验收 + 轴承来料管控**"，而不是贴一张"极限法不通过"的红牌。

反过来补一句：概率法算出来的 0.131% 要靠供应商的轴承宽度分布真的是正态、且 Cpk ≥ 1.33 才站得住。
**图纸上写概率法，采购单上就得跟得上抽检**，否则那 0.131% 只是纸面数字。

## 错误 5：漏掉 GD&T 的贡献

尺寸链只算尺寸公差是很自然的习惯，因为图纸上几何公差是另外一栏、由另外一套逻辑标注。
但在装配链里，几何误差和尺寸误差**占用的是同一个间隙**。

案例 3（塑胶壳—五金支架—PCB 叠装，脱敏）只算三条尺寸时：

- 极值法 T0 = 0.500，区间 4.650 ~ 5.150，要求 4.70 ~ 5.10 → 不通过
- 于是看概率法：T0 = 0.3499，**超差率 0.061%，判通过**

把图纸上真实存在的两条几何公差加进来——塑胶柱端面平面度 0.08、五金支架平面度 0.05：

- 极值法 T0 涨到 0.630
- 概率法 T0 从 0.3499 涨到 **0.3861**
- 更要命的是：这两条是**单向**公差（形状误差只会吃掉间隙，不会增加间隙），
  各自的中间偏差 −0.04 和 −0.025 一起把分布中心压低 **0.065 mm**
- 结果：Cpk **0.699**，超差率 **1.80%**，而且**全部落在下限侧**——也就是压不紧/干涉的那一侧

只算尺寸会得到"极值不行、概率 0.06% 通过"的绿色结论；算上 GD&T 才发现"概率 1.80% 也不行，
而且坏在干涉侧"。一条公差都没改，结论直接反转——这就是漏算几何公差的代价。

v2 方案只把塑胶柱名义高度加 0.065（模具镶件微调），公差一个没动，超差率降到 **0.188%**，
Cpk 从 0.699 回到 1.036。

## 错误 6：分布系数 k 空着，或者全填 1

RSS 的教科书式子常写成 T0 = √ΣTi²，那是**默认各环正态、k=1**。
注塑件、冲压件的分布往往偏态或更宽；平面度、平行度这类形状误差在公差带内更接近均匀分布。

案例 3 里塑胶柱取 k=1.17、两条平面度取 k=1.73，与全部按 k=1 相比：

| 口径 | T0（RSS） | 预测超差率 |
|---|---|---|
| 全部 k=1 | 0.3318 | 0.73% |
| 按实际分布 | **0.3861** | **1.80%** |

T0 低估 14%，超差率低估 2.5 倍。对一条本来就在边缘的链，这个差距足以让判断从"可接受"翻成"必须改"。

## 错误 7：把公差分配当万能钥匙（顺便：分配不该放宽）

"超差了？那把公差收一收。"——这句话经常对，但有时完全无效。

案例 1 原始设计按等精度法把 T0 从 0.370 压到 0.247（目标 0.25），回验结果：

- 极值法 0.1615 ~ 0.4085，**仍然不通过**
- 概率法超差率 **26.34%**，比原来的 31.97% 只好了一点点

因为中心偏移 Δ0 = +0.135 一分没动。**分配只能压缩带宽，压不掉中心偏移。**
先做名义补偿（错误 3 的做法），再用分配把极值法走通，是正确的顺序：
案例 1 v2 先补偿 +0.11，再按建议值收紧（A1 ±0.0275、A3 ±0.023、A4 ±0.013），
回验极值法 **0.0515 ~ 0.2985**，完全互换，一次通过。

另外两个分配时容易犯的工程错误：

- **给已经够紧的环建议更松的公差**。某隔套已经磨到 ±0.01，算法按等精度法算出 ±0.05 就照抄，
  等于自己放松了图纸。分配应当**只收紧、不放宽**：这些环保持原值，省下的预算让给其它环。
  本文工具用"水位填充"实现这一点。
- **概率法口径下按线性求和分配预算**。概率法的合成是 √Σ(kT)²，如果分配时却按 ΣT = T0 拆，
  就会得到"分配说可行、回验却超差"的自相矛盾结果。

## 附：手算自检清单

每次交计算书前扫一遍，能拦掉绝大部分错误：

1. **符号**：减环的 ES/EI 是否交叉取？算出来 ES0 < EI0 就是信号。
2. **区间**：是否用了 A0 ± ΣT/2 的对称假设？各环偏差不对称时必须算 Δ0。
3. **中心 vs 宽度**：Cp 和 Cpk 都看了吗？Cp 高 Cpk 低 → 动名义尺寸，不动公差。
4. **标准件**：轴承、垫片、PCB 宽度这些"0/−x"的环，是不是已经吃掉了大半预算？
5. **GD&T**：平面度、平行度、跳动、同轴度是否入链？它们的单向性是否体现在中心偏移里？
6. **分布**：k 是否按工艺分别取值（正态 1.0 / 三角 1.22 / 均匀 1.73）？
7. **分配顺序**：先补偿中心，再压缩带宽；分配只收紧不放宽；分配完必须回验。
8. **单位与位数**：全程 mm，偏差别丢 0.005；IT 等级反算用的是 µm 公差因子，别混。
